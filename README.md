# Boîte à outils automaticien — FSI Automation

Appli web installable (iPad, iPhone, PC), utilisable hors ligne : GRAFCET, chaîne cinématique, test logique SCL/LIST, calculs de mise en service, réglage PID, cadence de ligne, sondes de température, défauts variateurs SEW / SINAMICS, résistance de freinage, conversions, réseau.

Installation sur iPad : ouvrir https://fsi-auto.github.io/Outils/ dans Safari → Partager → « Sur l'écran d'accueil ».

Fichiers générés : `index.html` (l'appli complète), `sw.js` (cache hors ligne), `manifest.webmanifest` et `icons/`.
